# نظام إدارة المدرسة (School Management System) 🎓

نظام إدارة مدرسة متكامل واحترافي مبني باستخدام أحدث تقنيات الويب، مصمم خصيصاً ليتوافق مع احتياجات المدارس العربية بواجهة مستخدم عصرية وسهلة الاستخدام، ويدعم اللغة العربية بالكامل (RTL).



## 🌟 المميزات الرئيسية

- **واجهة مستخدم عصرية (UI/UX)**: تصميم احترافي، متجاوب بالكامل مع جميع الشاشات.
- **دعم كامل للغة العربية**: واجهة RTL 100٪ مع خط "Cairo" الأنيق والمريح للعين.
- **لوحة تحكم متكاملة**: إحصائيات سريعة للطلاب، المعلمين، الحضور، والإيرادات.
- **إدارة المستخدمين والصلاحيات**: 
  - مدير النظام (Admin)
  - المعلم (Teacher)
  - الطالب (Student)
- **إدارة الطلاب**: تسجيل وتعديل وعرض وحذف بيانات الطلاب بالإضافة لربطهم بالصفوف والشعب.
- **إدارة المعلمين**: تنظيم بيانات الكادر التعليمي ومتابعة رواتبهم وتخصصاتهم.
- **لوحة مهام سريعة**: روابط سريعة لإضافة طلاب أو إرسال إشعارات وإنشاء فواتير.
- **تصميم آمن**: معالجة حماية الجلسات وتشفير كلمات المرور وحماية مسارات النظام.

---

## 🛠 التقنيات المستخدمة

- **الواجهة الخلفية (Backend)**: Laravel (النسخة المستقرة الأحدث)
- **قاعدة البيانات**: MySQL
- **الواجهة الأمامية (Frontend)**:
  - HTML5 & CSS3
  - Tailwind CSS v4 (لبناء واجهات عصرية ومتجاوبة)
  - JavaScript
  - Blade Templating Engine
- **أيقونات**: FontAwesome 6

## 📂 هيكل المشروع (المجلدات المهمة)

```text
school-management-system/
├── app/
│   ├── Http/Controllers/    # أجهزة التحكم (Auth, Dashboard, Student, Teacher...)
│   ├── Models/              # نماذج قواعد البيانات والعلاقات (User, Student, Teacher...)

│   ├── migrations/          # ملفات بناء الجداول (Students, Teachers, Grades...)
│   └── seeders/             # بيانات تجريبية (Admin, Users, Sections...)

│   └── assets/              # الأيقونات، الصور، والوسائط المتعددة (قم بإضافتها هنا)
├── resources/
│   ├── css/                 # ملفات تصميم Tailwind CSS
│   └── views/               # واجهات النظام (Blade Files)
│       ├── auth/            # صفحة تسجيل الدخول
│       ├── dashboard/       # لوحة التحكم الرئيسية
│       ├── layouts/         # القالب الرئيسي للنظام (app.blade.php)
│       ├── students/        # صفحات إدارة الطلاب
│       └── teachers/        # صفحات إدارة المعلمين
└── routes/
    └── web.php              # مسارات النظام (Routes)
```

## 🚀 طريقة التثبيت والتشغيل

اتبع الخطوات التالية لتشغيل المشروع في بيئتك المحلية:

1. **نسخ المشروع / استنساخه**:
   تأكد من وجود الملفات في خادمك المحلي (مثل XAMPP أو Laragon).

2. **تثبيت مكتبات Composer**:
   ```bash
   composer install
   ```

3. **تثبيت مكتبات Node.js (لـ Tailwind CSS)**:
   ```bash
   npm install
   npm run build
   ```

4. **إعداد ملف البيئة (.env)**:
   تأكد من إعداد بيانات قاعدة البيانات `MySQL`:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=school_management
   DB_USERNAME=root
   DB_PASSWORD=
   ```

5. **إنشاء قاعدة البيانات**:
   قم بإنشاء قاعدة بيانات باسم `school_management` في `phpMyAdmin`.

6. **تهيئة الجداول والبيانات التجريبية**:
   ```bash
   php artisan migrate --seed
   ```

7. **تشغيل الخادم المحلي**:
   ```bash
   php artisan serve
   ```
